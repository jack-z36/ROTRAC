# 扭转运行时使用解析梯度，禁止数值差分

扭转精修的每帧候选评估使用解析梯度：Pinocchio 一次 FK 给出三个 tip 的位置和完整 3×16 平移雅可比；O10 耦合模型给出完整 16 关节对 6 个 tripod 主动关节的解析雅可比；closure、centroid、法向、轴偏差和两条平面内向量的平均有符号角按链式法则求导。运行时只做固定次数的投影负梯度迭代，不调用有限差分。

解析梯度必须在离线测试中与中心差分独立对照，覆盖左右手、多个关节状态和接近限位但仍合法的状态。生产代码不保留数值差分路径，也不允许用“调试开关”在运行时切换成差分。

这样选择的原因是每帧预算：扭转精修位于 baseline IK 之后、低通之前，运行在 30 Hz 输入链路上；对 6 个变量做中心差分会把每帧 FK 次数放大到 13 倍，并且把数值噪声带进 trust region 和回溯判定。代价是解析推导更复杂，尤其是平均有符号角、单位法向和 closure 距离的链式法则；这些推导由纯核心测试和真实资产梯度测试锁定。

该决策与 ADR-0002 同源：单指 IK 已采用“Pinocchio 平移雅可比 × 耦合雅可比”的解析梯度，中心差分只作离线参考。扭转层沿用同一原则。
