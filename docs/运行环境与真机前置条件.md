## Python 数值环境与 ROS 环境是两个独立边界

- **数值 Python**：仓库根 `.venv`（Python 3.12，Pinocchio / NLopt / NumPy，经 cmeel.pth 接入；vendor omnihand SDK 亦在此）。可用环境变量 `DEXHIT_COLLECTION_PYTHON` 覆盖。重建数值依赖见 `scripts/requirements.txt`。**不要用缺少数值依赖的系统 Python 替代**；`No module named pinocchio` 几乎总是环境没对。
- **ROS Jazzy**：`source /opt/ros/jazzy/setup.bash`；使用本仓构建产物还须 `source <仓库根>/install/setup.bash`。
- 二者都生效才算运行环境就绪。重定向节点的 wrapper（`src/hand_retargeting_node/scripts/hand_retargeting_node`）会强制校验 `DEXHIT_COLLECTION_PREFIX`（默认由启动脚本设为 `<仓库根>/.venv`）与 `OMNIHAND_O10_MODEL_FIXTURE`（默认 `<仓库根>/omnihand_o10_model`，须含 `provenance.json`），缺一即 `BLOCKED_ENV`——这是故意的 fail-closed。

## Launchpad 控制面

`rokoko_omnihand_launchpad` 是本机设备编排层，控制面监听 `http://127.0.0.1:8710`（架构门禁强制此绑定）。

运行前应满足：数值 Python 环境可用；ROS Jazzy 已 source；真机模式所需 ROS 包、参数档案和厂商节点已进入当前 install 空间；数值依赖、设备枚举和参数预检全部通过。

**安全红线**：Launchpad 网页不提供任何操作/授权 Service（`arm`/`disarm` 已移除，网页亦不暴露 `clear_fault`）。运动由新鲜合法软目标直接驱动——只要反馈就绪、错误监控就绪且目标新鲜，实体手就会动。**网页启动成功、topic 有发布者或反馈可读，都不能单独证明实体手已经安全**；戴手套前必须确认实体手周围安全，且只连接真机 provider（不要同时点亮合成输入源——合成假帧喂进真机链会直接驱动实体手）。

## OmniHand O10 设备前置条件

每次真机启动前重新逐项确认（"已连接"只是现场前提，不是永久断言）：

1. USB-CANFD 设备身份、权限和 CAN 通道正确枚举（已知 HCAN 识别条件：USB VID:PID `a8fa:8598`，可用 `lsusb -d a8fa:8598` 验证；这是设备预检条件，不是枚举结果断言）；
2. 左右侧 Provider 连接到预期实体设备；
3. 反馈新鲜、关节值有限且在合法范围（经 `/o10/{side}/read_active_joints` 无动作读取验证）；
4. `fault_latched=false`、控制状态允许进入下一阶段（无 `arm`；运动由新鲜目标直接驱动，无独立使能前置检查）。

断开、身份不匹配、反馈不新鲜或故障锁存均属于**停止条件**。

## 验证入口（低风险 → 高风险）

```bash
./scripts/init_omnihand.sh
```

统一检查：仓库根、ROS Jazzy、数值环境（`.venv` import 检查）、模型 fixture 与 provenance、x64/Jazzy Agilink SDK（`src/third_party/agillink_omnihand_sdk/linux/x64/ros2/jazzy/`，由 `third_party/COLCON_IGNORE` 与自有源码隔离）、11 个自有包、遗留 ROS 图（默认检测到活节点即 fail，需 `--allow-live-graph` 才放行）。**它不会启动节点、发布命令、清故障或接触实体手**；依赖安装需显式 `--install`。

随后才依次运行 Launchpad preflight → 数据链路/sim 验证 → 真机。真机验收需要独立的会话目录、MCAP、`/rosout`、事件时间线和系统监控证据；软件单元测试不能替代。

真机启动操作本身遵循《全流程启动手册》。

## 已知环境备注

- 仓库路径含中文会使 rosidl 接口生成失败（CMake `file(STRINGS)` 非 ASCII 拆行，根因已实锤）——当前构建基线修复进行中，见 `.scratch/build-baseline-fix/`；在此之前构建门可能被卡。
- Web 栈（fastapi/uvicorn）用系统 Python，与数值 `.venv` 是两套：若 Launchpad 辅助依赖（如 `click`/`yaml`）在所选解释器中不可见，先复核环境激活与依赖安装，不要混用两套 site-packages。
