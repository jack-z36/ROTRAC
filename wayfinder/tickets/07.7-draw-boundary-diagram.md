## Question

基于前序决策，绘制完整的模块边界图，清晰标识各层职责与接口。

**图中必须包含**：
1. **三层结构**：
   - 手套侧适配层（Glove Adapter）
   - 中段处理层（Normalization + IK + Smoothing）
   - 手侧适配层（Hand Adapter）

2. **每层的职责边界**：
   - 输入输出数据类型（RawHandFrame → ??? → JointTargets → 厂商命令）
   - 配置依赖（哪些层依赖 HandProfile/配置文件）
   - 外部依赖（vendor SDK、MJCF/URDF、launchpad）

3. **接口契约标注**：
   - 每个箭头标注接口名称与数据类型
   - 关键接口标注是否「手无关」（通用契约）还是「手相关」（需 HandProfile）

4. **换手影响范围**：
   - 用颜色/标记区分「换手必改」vs「换手不动」的模块
   - 标识 HandProfile 注入点

**产出格式**：
- Mermaid 图（可纳入 markdown 文档）或 draw.io/excalidraw（导出 SVG）
- 保存为 `diagrams/hand-adapter-module-boundaries.svg` + 对应的源文件
- 图中包含简短文字说明关键设计决策

**说明**：本票据为 task 类型（落地执行），agent 可独立完成绘图；若需工具支持可请求用户协助。
