## Question

通过具体原型明确「HandProfile/HandAdapter」模块的形状，回答票据 07 的问题 1 核心部分。

**原型目标**：
创建一个草稿级的 `HandProfile` 与 `HandAdapter` 接口定义（Python protocol/ABC），具体到：

1. **HandProfile 封装什么**：
   - 关节名清单、DOF、限位（`o10_contracts/joints.py` 的内容）
   - MJCF 主动-被动耦合配置
   - URDF 几何描述的路径/引用
   - 触觉分区映射
   - 是否包含运动学参数（IK 专调、平滑常数）？

2. **HandAdapter 接口签名**：
   ```python
   class HandAdapter(Protocol):
       def send_target(self, joint_targets: Dict[str, float]) -> Result[None, HandError]:
           """输入：软目标关节角；输出：厂商命令发送结果"""
           ...
       
       def get_feedback(self) -> HandFeedback:
           """反馈：当前关节角、错误位、硬件状态"""
           ...
   ```
   - 错误处理如何进契约（异常 vs Result 类型）？
   - 反馈机制是同步查询还是异步回调？

3. **backends.py 作为唯一 vendor SDK 触点**的实现位置：
   - 是 HandAdapter 的具体实现类（如 `O10HandAdapter`）？
   - 还是更底层的 transport 层？
